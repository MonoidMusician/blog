This is a post about different shapes that come up in category theory / abstract algebra, themes that pop up and recur time and time again, little bits of terminology that you could figure out by context but never get explained, and the like.

If you want to formalize category theory, you can do it in a completely formal, non-circular way.

But the concepts are undeniably circular: they reference each other if you let them, each one can be phrased in a more abstract way or demonstrated as a specialization of something else.
So keep in mind that a linear reading of this list is not possible.
